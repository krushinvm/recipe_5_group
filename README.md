# recipe_5_group
# Recipe Finder API

Прототип RESTful-сервера для подбора рецептов. Написан на Python (FastAPI).

## Описание эндпоинтов

| Название действия | URL | Тип запроса | Описание запроса и ответа |
| :--- | :--- | :--- | :--- |
| Проверка статуса | `/` | GET | Возвращает сообщение о том, что сервер работает. |
| Добавить рецепт | `/recipes` | POST | Принимает JSON: `name` (строка), `rating` (число от 0 до 5), `ingredients` (массив объектов с `name` и `quantity`). Возвращает созданный рецепт с присвоенным `id` (UUID). |
| Подобрать рецепты | `/recipes/search` | POST | Принимает JSON-массив продуктов пользователя (`name`, `quantity`). Возвращает список рецептов, которые можно приготовить, отсортированных по убыванию рейтинга. |
